Python Libraries for Data Analysis

📌 Project Overview

This project is a practical collection of **Python data analysis exercises** designed to build hands-on experience with four important Python libraries:

* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical and statistical calculations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical data visualization

The project is divided into **three levels — Easy, Intermediate, and Expert** — with each level using real-world style datasets and progressively more advanced data analysis techniques.



🟢 1. Easy Level – Retail Sales Analysis

The Easy project focuses on learning the fundamentals of Python data analysis using a **Retail Sales dataset**.

Key Tasks

* Load and inspect the dataset
* Understand rows, columns, and data types
* Check missing values
* Clean and prepare the data
* Filter and sort records
* Create calculated columns
* Perform basic statistical analysis
* Group and aggregate data
* Analyze sales-related information
* Create basic visualizations
* Extract useful business insights

Libraries Used

**Pandas | NumPy | Matplotlib | Seaborn**

---

🟡 2. Intermediate Level – E-Commerce Analytics

The Intermediate project focuses on analyzing an **E-Commerce dataset** containing information about orders, customers, and products.

Key Tasks

* Load and inspect multiple datasets
* Perform data cleaning and preparation
* Analyze customers, products, and orders
* Filter and sort data
* Create calculated columns
* Perform grouping and aggregation
* Analyze sales and customer-related patterns
* Perform numerical calculations using NumPy
* Create charts to understand business trends
* Identify useful analytical insights

Libraries Used

**Pandas | NumPy | Matplotlib | Seaborn**

---

🔴 3. Expert Level – Fintech Loan Risk Analysis

The Expert project analyzes a **Fintech Loan Risk dataset** to understand borrower characteristics, loan performance, and financial risk.

Key Tasks

* Load and audit loan data
* Check data types, missing values, blanks, and invalid values
* Validate business rules such as credit score and income
* Calculate percentiles and statistical measures
* Perform manual and built-in statistical calculations
* Calculate EMI using NumPy
* Analyze debt burden and loan exposure
* Categorize borrowers based on risk
* Analyze default rates
* Identify high-risk defaulted loans
* Perform correlation analysis
* Create advanced visualizations
* Export the final analyzed dataset

Visualizations

* Correlation Heatmap
* Credit Score Histogram
* Box Plot
* Violin Plot
* Scatter Plot
* KDE Plot
* Horizontal Bar Chart
* Risk Distribution Chart

### Libraries Used

**Pandas | NumPy | Matplotlib | Seaborn**
